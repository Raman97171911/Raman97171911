## 👋 About me

I'm a **Linux & Network Engineer** who learns by building. My home lab runs on **VMware + EVE-NG**, with Red Hat servers, Cisco routers and switches, firewalls, and Kubernetes clusters that I set up, break and fix.

- 🎯 **Goal:** Red Hat Certified Architect (**RHCA**)
- 🔭 **Building now:** [CCNA 101 Labs on EVE-NG](https://github.com/Raman97171911/CCNA-101-Labs-EVE-NG), one ready-to-import lab every day
- 🌱 **Learning:** Ansible automation · CCNP · Firewall design · Python for network automation
- 🧪 **Home lab:** VMware Workstation · EVE-NG · RHEL 9 · Cisco IOL · FortiGate · kubeadm K8s
- 💬 **Ask me about:** Linux administration, VLANs and routing, Ansible playbooks, EVE-NG lab setup
